<h1 align="center">💍 Ringly</h1>

<p align="center">
  Crie lindos anéis 3D em tempo real com o Ringly. Personalize as cores das pedras preciosas, gire sua criação de todos os ângulos e aproveite uma experiência WebGL fluida construída com React Three Fiber.
</p>

## <img src="https://github.com/KrishBharadwaj5678/Ringly/raw/main/src/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
| -------------- | --------- |
| 🎨 **Personalização do Anel** | Altere cores e estilos de pedras preciosas instantaneamente |
| 🌀 **Controles 3D Suaves** | Gire, aplique zoom e mova a câmera com controles intuitivos de mouse/toque |
| 💡 **Iluminação Dinâmica** | Reflexos realistas e diferentes configurações de ambiente |
| 💎 **Renderização de Alta Qualidade** | Desenvolvido com WebGL + R3F para uma aparência premium |
| 🖥️ **Interface Responsiva** | Funciona em computadores e dispositivos móveis |

## <img src="https://github.com/KrishBharadwaj5678/Ringly/raw/main/src/assets/readme/gettingStarted.gif" width="35"/> Começando

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Ringly.git
````

### 2️⃣ Acesse o diretório do projeto

```bash
cd Ringly
```

### 3️⃣ Instale as dependências

```bash
npm install
```

### 4️⃣ Execute o servidor de desenvolvimento

```bash
npm run dev
```
