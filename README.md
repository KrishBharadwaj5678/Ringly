<h1 align="center">💍 Ringly</h1>

<p align="center">
  Design beautiful 3D rings in real time with Ringly. Customize stone colors, rotate your creation from every angle, and enjoy a smooth WebGL experience built with React Three Fiber.
</p>

## <img src="https://github.com/KrishBharadwaj5678/Ringly/raw/main/src/assets/readme/features.gif" width="35"/> Features

| Feature                       | Description                                             |
| ----------------------------- | ------------------------------------------------------- |
| 🎨 **Ring Customization**     | Change colors and gemstone styles instantly             |
| 🌀 **Smooth 3D Controls**     | Rotate, zoom & pan with intuitive mouse/touch controls  |
| 💡 **Dynamic Lighting**       | Realistic reflections & environment presets             |
| 💎 **High-quality Rendering** | Powered by WebGL + R3F for a premium look               |
| 🖥️ **Responsive UI**         | Works across desktop and mobile devices                 |

## <img src="https://github.com/KrishBharadwaj5678/Ringly/raw/main/src/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository
   
```bash
 git clone https://github.com/KrishBharadwaj5678/Ringly.git
```

### 2️⃣ Navigate to the Project

```bash
 cd Ringly
```

### 3️⃣ Install dependencies

```bash
 npm install
```

### 4️⃣ Run development server

```bash
  npm run dev
```
