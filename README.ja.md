<h1 align="center">💍 Ringly</h1>

<p align="center">
  Ringlyを使って、美しい3Dリングをリアルタイムでデザインしましょう。宝石の色を自由にカスタマイズし、あらゆる角度からリングを回転させながら、React Three Fiberで構築された滑らかなWebGL体験をお楽しみください。
</p>

<img src="https://github.com/KrishBharadwaj5678/Ringly/raw/main/src/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/Ringly/raw/main/src/assets/readme/features.gif" width="35"/> 主な機能

| 機能 | 説明 |
| ---- | ---- |
| 🎨 **リングのカスタマイズ** | リングのカラーや宝石のスタイルをリアルタイムで変更できます。 |
| 🌀 **スムーズな3D操作** | マウスやタッチ操作で回転・ズーム・パンを快適に行えます。 |
| 💡 **ダイナミックライティング** | リアルな反射表現と環境ライティングプリセットを搭載。 |
| 💎 **高品質レンダリング** | WebGLとReact Three Fiberによる美しい3D描画を実現。 |
| 🖥️ **レスポンシブUI** | デスクトップ・モバイルの両方で快適に利用できます。 |

## <img src="https://github.com/KrishBharadwaj5678/Ringly/raw/main/src/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Ringly.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd Ringly
```

### 3️⃣ 依存関係をインストール

```bash
npm install
```

### 4️⃣ 開発サーバーを起動

```bash
npm run dev
```
