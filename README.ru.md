<h1 align="center">💍 Ringly</h1>

<p align="center">
  Создавайте красивые 3D-кольца в реальном времени с помощью Ringly. Настраивайте цвета драгоценных камней, вращайте своё изделие под любым углом и наслаждайтесь плавной работой WebGL, созданной на React Three Fiber.
</p>

## <img src="https://github.com/KrishBharadwaj5678/Ringly/raw/main/src/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ------------ | -------- |
| 🎨 **Настройка кольца** | Мгновенно изменяйте цвета и стили драгоценных камней |
| 🌀 **Плавное управление 3D** | Вращение, масштабирование и панорамирование с помощью удобного управления мышью и сенсорных жестов |
| 💡 **Динамическое освещение** | Реалистичные отражения и различные пресеты окружения |
| 💎 **Высококачественный рендеринг** | Основан на WebGL и React Three Fiber для премиального качества изображения |
| 🖥️ **Адаптивный интерфейс** | Корректно работает как на настольных компьютерах, так и на мобильных устройствах |

## <img src="https://github.com/KrishBharadwaj5678/Ringly/raw/main/src/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонируйте репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/Ringly.git
```

### 2️⃣ Перейдите в папку проекта

```bash
cd Ringly
```

### 3️⃣ Установите зависимости

```bash
npm install
```

### 4️⃣ Запустите сервер разработки

```bash
npm run dev
```
